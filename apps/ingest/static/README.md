# static

`InterVariable.woff2` is the Latin subset of Inter 4.1 that every zyx.tw site
serves, copied byte for byte from `packages/ui/src/fonts/` in
[zyx1121/www.zyx.tw](https://github.com/zyx1121/www.zyx.tw), whose README
there has the subset command. SIL Open Font License 1.1, see
[LICENSE.txt](LICENSE.txt). The landing page (`src/landing.ts`) serves it at
`/fonts/InterVariable.woff2`.

`favicon.ico` is the zyx mark icon from `apps/web/app/favicon.ico` in the same
repo, served at `/favicon.ico`.
